# Processo de Desenvolvimento

## Metodologia escolhida

Para o desenvolvimento do projeto ESM Forum foi escolhida a metodologia Kanban.

A escolha do Kanban ocorreu por ser uma abordagem simples e adequada ao tamanho do projeto. Como as funcionalidades podem ser desenvolvidas gradualmente, o Kanban permite acompanhar com facilidade o andamento das tarefas e visualizar o que ainda precisa ser realizado.

## Organização do trabalho

O acompanhamento das atividades será realizado utilizando o GitHub Projects.

O quadro foi organizado em três etapas:

- Todo: tarefas que ainda não foram iniciadas.
- In Progress: tarefas que estão sendo desenvolvidas.
- Done: tarefas concluídas.

Cada funcionalidade será representada por um card no quadro. Conforme o desenvolvimento avançar, os cards serão movimentados entre as etapas, permitindo acompanhar o progresso do projeto.

## Priorização das funcionalidades

As funcionalidades propostas para o ESM Forum serão priorizadas considerando sua importância para o funcionamento e para a experiência dos usuários.

A ordem inicial de prioridade será:

1. Busca de perguntas por palavra-chave.
2. Categorização de perguntas por tags.
3. Sistema de votação em perguntas (upvote/downvote).
4. Perfil de usuário com histórico de perguntas e respostas.
5. Notificação de novas respostas.

Essa priorização poderá ser ajustada durante o desenvolvimento caso sejam identificadas novas necessidades ou dependências entre as funcionalidades.
