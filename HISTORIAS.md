# Histórias de Usuário - ESM Forum

Este documento apresenta as histórias de usuário referentes a três funcionalidades propostas para a evolução do ESM Forum.

## História 1: Busca de perguntas por palavra-chave

**Como** usuário do fórum,  
**Eu quero** pesquisar perguntas utilizando palavras-chave,  
**Para** localizar mais rapidamente conteúdos relacionados à minha dúvida.

### Critérios de Aceitação

- [ ] O sistema deve disponibilizar um campo para informar o termo da busca.
- [ ] A busca deve considerar o texto das perguntas cadastradas.
- [ ] O sistema deve exibir as perguntas que correspondam ao termo pesquisado.
- [ ] Quando nenhuma pergunta for encontrada, o sistema deve informar ao usuário.
- [ ] O usuário deve conseguir realizar uma nova busca sem precisar recarregar a aplicação.

## História 2: Categorização de perguntas por tags

**Como** usuário do fórum,  
**Eu quero** visualizar e associar tags às perguntas,  
**Para** identificar com facilidade os assuntos relacionados a cada pergunta.

### Critérios de Aceitação

- [ ] Uma pergunta deve poder possuir uma ou mais tags.
- [ ] As tags associadas devem ser exibidas junto à pergunta.
- [ ] O sistema deve armazenar a associação entre perguntas e tags.
- [ ] As tags devem permanecer associadas à pergunta após uma nova consulta.
- [ ] O sistema deve permitir identificar perguntas relacionadas a determinado assunto por meio das tags.

## História 3: Sistema de votação em perguntas

**Como** usuário do fórum,  
**Eu quero** votar positiva ou negativamente nas perguntas,  
**Para** contribuir para a identificação das perguntas consideradas mais relevantes.

### Critérios de Aceitação

- [ ] Cada pergunta deve apresentar opções de upvote e downvote.
- [ ] O sistema deve registrar o voto realizado pelo usuário.
- [ ] A pontuação da pergunta deve ser atualizada após o voto.
- [ ] O usuário não deve conseguir registrar múltiplos votos iguais na mesma pergunta.
- [ ] O sistema deve permitir alterar um voto realizado anteriormente.

## Priorização

As histórias foram priorizadas considerando a utilidade imediata para os usuários e a evolução gradual do ESM Forum.

1. **Busca de perguntas por palavra-chave** - prioridade mais alta por facilitar o acesso às informações já cadastradas no fórum.
2. **Categorização de perguntas por tags** - complementa a organização e facilita a identificação dos assuntos das perguntas.
3. **Sistema de votação em perguntas** - acrescenta uma forma de avaliação da relevância das perguntas pela comunidade.

A ordem permite melhorar primeiro a localização e a organização das informações e, posteriormente, acrescentar um mecanismo de participação dos usuários na avaliação do conteúdo.
