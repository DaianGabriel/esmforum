# Pair Programming no ESM Forum

## Conceito

Pair Programming é uma prática de desenvolvimento em que duas pessoas trabalham em conjunto na implementação de uma tarefa. O objetivo é permitir a revisão contínua do código, a troca de conhecimento e a identificação de problemas durante o desenvolvimento.

## Papéis

A prática normalmente utiliza dois papéis:

- **Driver:** responsável por escrever o código e executar as alterações no projeto.
- **Navigator:** acompanha o trabalho, analisa o código, identifica possíveis problemas e sugere melhorias.

Os papéis podem ser alternados durante o desenvolvimento para que os dois participantes contribuam de maneiras diferentes.

## Aplicação no ESM Forum

No desenvolvimento do ESM Forum, o Pair Programming pode ser utilizado durante a implementação ou alteração das funcionalidades do backend e do frontend.

Enquanto o Driver realiza as modificações no código, o Navigator acompanha as decisões tomadas, verifica se os requisitos estão sendo atendidos e sugere correções quando necessário.

Após determinado período ou após a conclusão de uma pequena tarefa, os papéis podem ser invertidos.

## Ferramentas

A prática pode ser realizada presencialmente ou remotamente. Em um ambiente remoto, podem ser utilizadas ferramentas de compartilhamento de tela, comunicação por voz e recursos de desenvolvimento colaborativo.

## Adaptação ao desenvolvimento individual

Neste projeto acadêmico, o desenvolvimento está sendo realizado individualmente. Dessa forma, os princípios do Pair Programming podem ser parcialmente aplicados por meio da revisão das alterações após a implementação, execução de testes e análise do código antes de realizar commits no repositório.

Essa adaptação não substitui uma sessão real de Pair Programming, mas permite aplicar alguns de seus princípios, principalmente revisão, reflexão sobre as decisões de implementação e verificação contínua do código.
